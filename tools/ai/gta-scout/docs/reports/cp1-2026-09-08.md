# CP1 real relevance rerun — 2026-09-08

**CP1 is not complete.** The public evaluator reproduces a real failure on the
existing local catalogue: 5 of 22 independently known direct candidates are
retrieved in the semantic top 30 (22.73%; target 90%). Synthetic tests validate
the evaluator's accounting, not the game's relevance thresholds.

## Scope and independence

This rerun preserves an earlier frozen set of 24 French requests: 16 model and
8 texture requests, with explicit visible constraints. The historical auditor
made 100 visual judgments on candidate pools selected through catalogue
exploration outside retrieval. A further render failure was recorded separately
and excluded from the visual judgment count. The pools include related
distractors, verified negative/constraint controls and unresolved appearances.

There are 22 known direct candidates across 10 requests. Texture judgments use
independently audited exact-pixel groups, preserving occurrence identities;
they do not claim interchangeable runtime bindings. These are finite,
deliberately explored pools, not an exhaustive or random sample of the game.
The other 14 requests are not thereby proven impossible.

The source is a private local SA catalogue with mod extras: 50,017 entries,
including 16,838 models and 33,179 texture occurrences. It contains 3,068 direct
visual annotations and 2,494 exact-pixel transfers. No dataset, annotations,
game binaries, image evidence or source paths are distributed with this report.
These counts are not a vanilla-installation specification or a fresh-install result.

Search ran against a consistent SQLite backup using the public code and pinned
`intfloat/multilingual-e5-small` encoder, revision
`614241f622f53c4eeff9890bdc4f31cfecc418b3`. No ranking weights, query expansions or
annotations were tuned for this rerun. An explicit vector build on the isolated
copy found 5,562 unchanged vectors and zero pending embeddings. Existing evidence
was hash-checked; no new visual labels were fabricated.

The current operator subsequently read the misses. Any future tuning using
these cases must be called a development regression and confirmed on a new
independent holdout. Historical visual review costs and reviewer independence
cannot be re-established from image hashes alone.

## Observed results

The semantic run is the primary reported baseline. The other modes are
diagnostics and were not selected as a passing winner.

| Retrieval | Known direct found in first 30 | Recall@30 |
| --- | ---: | ---: |
| Semantic, exact-pixel diversity | 5 / 22 | 22.73% |
| Hybrid RRF diagnostic, exact-pixel diversity | 4 / 22 | 18.18% |
| Lexical diagnostic | 3 / 22 | 13.64% |

The hybrid diagnostic applies the public RRF formula to the captured top 100
per channel, then diversifies and cuts to 30. It is a diagnostic script result,
not a separately timed `run --mode hybrid` campaign. The shipped evaluator's
actual semantic run was executed separately on all 24 requests; every top-30
list exactly matches the first capture.

Of the 17 semantic misses, **16 have no fresh usable description** in any
independently audited equivalent occurrence. One has a fresh description but
is absent even from the captured top 100. This separates coverage failures from
ranking failures. Missing annotations remain in recall's denominator; scoring
only covered candidates would hide the principal defect.

| Semantic coverage | Fresh embedded documents | Assets in scope |
| --- | ---: | ---: |
| Models | 1,845 | 16,838 |
| Texture occurrences | 3,717 | 33,179 |

Only 6 of the 120 raw semantic top-five positions overlap the historical
independent judgments, of which 4 are direct. **Raw precision is unmeasured**;
the remaining 114 are unjudged, not automatically irrelevant. No independent
final-answer campaign was completed in this rerun, so final precision, positive
answer rate, abstentions and verified final constraint violations are also
unmeasured. They must not be reported as 100%, zero violations or passes.

## Timing and costs

Hardware: Apple M3 Pro, 18 GiB RAM, macOS 26.2 arm64; encoder uses CPU.
The repeated public semantic capture used cached local weights and warm files:

- Encoder initialization: 11.19 seconds.
- Total search time for 24 queries: 120.87 seconds.
- Per-query p50: 6.90 seconds; p95: 8.37 seconds (nearest-rank, n=24).

Search timings include the public freshness checks and texture diversification.
They exclude the SQLite backup, earlier vector validation/build, rendering,
annotation and final visual review. No paid inference API is called by the local
embedding implementation. Agent subscription/token costs, electricity and the
historical review cost were not metered; they are unknown, not free. This is not
a cold-start, storage or full-source throughput benchmark for CP3.
