Install

  1. Get the game ready

    GTA San Andreas for Android (2.00 or newer) with the AML mod loader installed.

  2. Copy the mod

    Download the latest release. Put libMP32.so and libMP64.so into the AML mods folder. Optional: broker.txt goes into Android/data/com.rockstargames.gtasa/files/MP.

  3. Start and pick a name

    Open the game, tap the MP button, set your player name. The region with the lowest ping is chosen for you.

  4. Play

    Tap Connect for your region's default server, or host your own with a name and an optional password.

Run a region

Each region is one Linux server with a HiveMQ broker and the region's 24/7 default server. One command sets it all up: Java 21, HiveMQ Community Edition, logins, firewall, TLS and restart on crash.

HiveMQ server repo and guide

git clone https://github.com/ThirtyFoxMCx00E1/HiveMQ
cd HiveMQ
sudo ./install.sh --region Asia \
  --domain asia-you.duckdns.org --email you@mail.com

# on ONE server only: join the server lists
sudo ./install.sh --region Asia --bridge

Security

Logins on every broker

No anonymous connections. Passwords are stored hashed. The game login can only use the mod's own topics.

Private player channels

Only you can read the messages a server sends to you, and nobody can send in your name.

Hidden IPs

Players connect through the broker, so phones never see each other's IP address.

Read-only website

This page holds no secrets. Its login can only read the server list, over encrypted WebSocket.

Flood limits

Connection, packet size and bandwidth limits per client. Idle sockets without a login are dropped.

Hardened servers

Firewall with only the needed ports, admin port off, services run as a locked-down user.
