One page for the whole Oracle part. Your key never leaves this browser unencrypted: it is sealed with the HiveMQ repo's public key (the same libsodium sealed box GitHub uses) and only GitHub Actions can open it.

1 GitHub token

Make a fine-grained token: Repository access = only HiveMQ; permissions: Secrets, Variables and Actions = Read and write.

2 Oracle API key

Oracle Cloud: Profile → API keys → Add API key → Download private key, then copy the config text it shows.

3 MP region

Free Oracle servers only exist in the account's home region, so one Oracle account = one low-ping MP region.

Optional: DuckDNS + Discord

4 Save and claim
